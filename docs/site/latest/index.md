# Libri documentation

Libri is a desktop frontend for your [DriveThruRPG](https://www.drivethrurpg.com/)
library: browse your catalog, organize it into collections, and download your
purchases, on macOS, Linux, and Windows. This is the latest documentation.

## Getting started

- [Installation]({{ '/latest/install/' | relative_url }}) - download a packaged
  release and get past the macOS/Windows unsigned-build warnings on first run.
- [Themes and appearance]({{ '/latest/themes/' | relative_url }}) - the six
  built-in color themes, density, and font settings.

Select a release from the version picker when working with an earlier build.
